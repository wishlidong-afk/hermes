## 1. 总体搭建逻辑

本轮系统按 greenfield v3 思路重新搭建，不把旧系统直接搬过来，而是把旧逻辑拆成可审计、可回放、可测试的模块链路：

```text
data -> features -> scoring -> decision -> portfolio -> routing -> reentry -> backtest/web
```

核心原则：

- 不下单，只输出建议、目标仓位、资金路由、再建仓审计和审计日志。
- 缺数据不等于安全，所有缺失都进入 `missing_weight` 和盲区惩罚。
- 每个因子必须声明依赖字段、最大分、缺失标签和评分函数。
- 价格类核心尽量本地 OHLCV 可算，不依赖外部软数据。
- 硬阀门优先级高于总分，触发即强制防守裁决。
- 组合层控制三条高 beta 仓位的共同风险。
- WebUI 只读，不能改变决策。
