## 结论:`use_hm2_buffer` 保持 **关**(回测否决)

诊断(中位 fwd20 +18%、0% 崩盘命中)**过度承诺**了——全窗口回测里缓冲净负:

1. **75% 与 50% 结果一模一样** → 说明缓冲触发的那些"孤儿 H-M2"日,**次日就有真阀门(H-M1/H-M4/H-M6)确认并强制 100% EXIT**;所以保留 75% 还是 50% 无所谓,都在次日清光。缓冲的净效果 = **把全清推迟一天**。
2. 那些孤儿 H-M2 日**平均还要再跌一天**(真阀门次日才确认),所以推迟一天清仓 = 在更低价清,**损失 −0.30pp CAGR**。
3. 诊断的"中位 +18% 反弹"是**孤立测**(从触发点往后 20 日),没算 in-system 路径;缓冲实际只延后约 1 天,几乎吃不到那个反弹,却吃满了即时续跌。

**这正是回测而非诊断说了算的价值**:median 前向收益骗了人,真实路径否决了它。代码保留(flag-gated 默认关、无副作用),标记为 backtest-rejected。
